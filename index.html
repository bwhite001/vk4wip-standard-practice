About the exam

ACMA formula sheet

These formulas are supplied in the Standard exam.

RT = R1 + R2 + R3
1/RT = 1/R1 + 1/R2 + 1/R3
LT = L1 + L2 + L3
1/LT = 1/L1 + 1/L2 + 1/L3
CT = C1 + C2 + C3 (parallel)
1/CT = 1/C1 + 1/C2 + 1/C3 (series)
E = IR · I = E/R · R = E/I
P = EI · P = E²/R · P = I²R
p = 1/f · f = 1/p
λ = c / f
Amplifier efficiency % = Power out / Power in × 100

Handy extras (not on the ACMA sheet)

RMS = 0.707 × peak
λ (m) ≈ 300 / f (MHz)
+3 dB ≈ ×2 · +6 dB ≈ ×4 · +10 dB = ×10
OWF ≈ MUF − 15%
